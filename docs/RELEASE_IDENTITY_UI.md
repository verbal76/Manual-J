# Settings → About, applying-update, studio splash
**About:** Home → ⚙ Settings → About / release diagnostics. Shows the same plain text that **Copy diagnostics** copies (clipboard API with textarea fallback). Sections: Application (name, version, source commit, build type, engine, project-data schema), Install (package ID, native versionName/versionCode via @capacitor/app — real installed values, runtime compatibility), Device (@capacitor/device: Android version/API, model, locale), OTA (enabled, channel, running from, id/name/seq/source/published, update state, last check/result), Google Play/Android (min/target/compile SDK read from `variables.gradle` at build time, Play requirement 36 verified 2026-10-03, compliant yes/no, signing state). Excludes project data, client info, secrets, endpoints. In a browser, native fields show n/a.
**Check for update now** appears only when updates are enabled; not needed for normal delivery.
**Applying update:** overlay with exact text "Please wait, applying update" (app card style + spinner, no fake percent). Shown only when state = `applying`, i.e. a verified staged payload is being activated at a safe point; removed on failure (watchdog 20 s, then a banner says the current version keeps running). Checking/downloading/failed/refused never show it.
**Studio splash (standing Hot Attic Games requirement):** every Hot Attic Games app opens with the studio card before its own title/menu. Canonical artwork: **`Hot_Attic_Games_Master_Logo_ALPHA_FINAL.png`** (repository root; 1536x1024 RGBA with transparency; owner-supplied, never modify, redraw or substitute it; the old `branding/Hot_Attic_Games_Master_Logo.png` path is obsolete). Markup and CSS are in `index.html` (so it is the first paint, no blank frame): opaque dark warm gradient card, logo `object-fit: contain`, centred, safe-area padding, logo fades in 450 ms, total 2.6 s with a 500 ms fade-out, silent, no text or extra effects. `src/ui/splash.ts` owns the timeline (hard cap 6 s; a missing/broken image removes the card; runs once per page load so background/resume never replays it; an update-activation reload sets a one-shot skip flag). The app initialises behind the card (nothing waits on it except the OTA safe-activation point). The native launch frame is solid black, so there is no white flash. The launcher icon is independent. The web card is OTA-safe; shipping it to an installed app needs either a native build (OTA is not configured yet) or an OTA. `tests/splash.test.ts` pins the file's git blob id (e11f8c5…), PNG size/alpha, contain-fit and timing; `tests/e2e/splash.mjs` checks it in a browser. Real-device verification is still PHYSICAL TEST REQUIRED.
